# Conjunto de Datos - Juegos Olímpicos

Los archivos originales de este proyecto no se encuentran en este repositorio por el tamaño de los datos. Para ejecutar los scripts y notebooks correctamente, deben ser descargados de forma local.

## Fuente y enlace de descarga
* **Plataforma:** Kaggle[cite: 1]
* **Dataset:** [120 years of Olympic history: athletes and results](https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results)[cite: 1]

## Archivos requeridos
Descarga el conjunto de datos y extrae los siguientes dos archivos[cite: 1]:
1. `athlete_events.csv`[cite: 1, 8]
2. `noc_regions.csv`[cite: 1, 8]

## Instrucciones de ubicación
Coloca ambos archivos `.csv` directamente dentro de esta misma carpeta (`data/`) en tu entorno local o Codespace[cite: 4, 5]:

```text
data/
├── README.md
├── athlete_events.csv
└── noc_regions.csv
