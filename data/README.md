# Descarga de conjuntos de datos

Los archivos CSV originales no se alojan en este repositorio por buenas prácticas de control de versiones. Para ejecutar el proyecto:

1. Descargue `athlete_events.csv` y `noc_regions.csv` desde Kaggle: [120 years of Olympic history](https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results).
2. Ubique ambos archivos directamente dentro de esta carpeta (`data/`).
