# Análisis Histórico de los Juegos Olímpicos (1896–2016)

## Descripción del Proyecto
Este proyecto consiste en un análisis exploratorio y estadístico sobre la historia moderna de los Juegos Olímpicos, abarca desde 1896 hasta 2016. A través del procesamiento de datos con Python y la librería Pandas, buscamos comprender cómo ha evolucionado la participación de los atletas a lo largo de más de un siglo, examinando factores como el género, la edad, las características físicas, las temporadas de competencia (Verano e Invierno) y el desempeño por países.

El trabajo se desarrolla de manera colaborativa bajo un flujo de control de versiones en GitHub, visualización de datos y documentación estructurada.

## Objetivos
* **Objetivo General:** Analizar las tendencias históricas, demográficas y deportivas de los atletas olímpicos mediante herramientas de manipulación y análisis de datos en Python.
* **Objetivos Específicos:**
  * Integrar y depurar los registros históricos de atletas y sus respectivos Comités Olímpicos Nacionales (NOC).
  * Evaluar el impacto de los datos faltantes a lo largo de las distintas épocas olímpicas.
  * Calcular indicadores derivados (como el Índice de Masa Corporal y tasas de éxito) para comparar el rendimiento entre grupos etarios, sexos, temporadas y países.
  * Generar visualizaciones claras y tablas resumen que respalden las conclusiones sobre los factores asociados a la obtención de medallas.
